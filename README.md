# Networking Labs

## Overview
This repository contains hands-on networking labs built using Windows and Linux virtual machines. The focus is on understanding how data moves across networks, how protocols behave, and how to analyse network traffic in real environments.



## Objectives
- Understand TCP/IP communication in practice
- Analyse DNS, routing, and subnetting behaviour
- Use tools like Wireshark and Nmap in controlled environments
- Develop practical networking troubleshooting skills



## Lab Environment
- Windows 10 VM
- Ubuntu Linux VM
- VirtualBox / VMware
- Wireshark
- Nmap



## Planned Labs

### Lab 1: Basic Network Communication
- Ping tests between VMs
- IP configuration analysis
- Observing connectivity behaviour

### Lab 2: DNS Analysis
- Domain resolution tracking
- Packet capture using Wireshark

### Lab 3: TCP/IP Analysis
- TCP handshake observation
- Packet inspection and breakdown

### Lab 4: Subnetting Practice
- Virtual network segmentation
- Communication between subnets

### Lab 5: Nmap Network Scanning
- Local network scanning
- Understanding open ports and services



## Skills Demonstrated
- Networking fundamentals
- Packet analysis (Wireshark)
- Network scanning (Nmap)
- Windows & Linux environments
- Troubleshooting network issues
